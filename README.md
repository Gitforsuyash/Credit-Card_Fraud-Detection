## 💳 Credit Card Fraud Detection
📌 Overview

This project focuses on detecting fraudulent credit card transactions using Machine Learning. The dataset is highly imbalanced, with fraudulent transactions representing only a small fraction of total records. The goal is to build a robust model that maximizes fraud detection accuracy while minimizing false positives.

# 🚀 Features

Exploratory Data Analysis (EDA): Visualized class imbalance, transaction patterns, and feature distributions.

Data Preprocessing:
Handled class imbalance using resampling techniques.
Feature scaling and normalization.
Model Development:
Implemented Random Forest Classifier for fraud detection.
Evaluated multiple ML models for comparison.
Model Evaluation Metrics:
Accuracy: 99.95%
Precision: 97.43%
Recall: 77.55%
F1-Score: 86.36%
MCC: 0.869
Visualization: Fraud vs. Non-Fraud distributions, ROC Curve, Precision-Recall Curve.

# 🛠️ Tech Stack

Programming: Python

Libraries: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

Algorithm: Random Forest Classifier

# 📊 Results

The Random Forest model achieved an excellent balance between fraud detection rate (recall) and false positive control (precision), making it suitable for real-world fraud detection pipelines.
